# 👑 Gremlin Kingdom

> The Official Encyclopedia of Gremlin Kingdom

A modern fantasy encyclopedia website built with **FastAPI**, **SQLite**, **HTML**, **CSS**, and **JavaScript**.

---

## ✨ Features

- 🏰 Beautiful Homepage
- 👑 Character Encyclopedia
- 📖 Kingdom History
- 🗺 Interactive Timeline *(Coming Soon)*
- 🖼 Gallery
- ⚙️ Admin Panel *(In Development)*

---

## 🛠 Tech Stack

- FastAPI
- SQLite
- HTML5
- CSS3
- JavaScript
- Jinja2

## 🚀 Run Project

```bash
uvicorn main:app --reload
```

Then open

```
http://127.0.0.1:8000
```
